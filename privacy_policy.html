Privacy Policy

Smart Form Filler Chrome Extension  ·  Last updated: June 2026

✓ Smart Form Filler does not collect, transmit, or share any personal data. Ever.

1. Overview

Smart Form Filler is a Chrome browser extension that helps you automatically fill web forms using profiles and general details you save yourself. This privacy policy explains what data the extension stores, where it is stored, and how it is used.

2. Data We Collect

We do not collect any data. The extension only stores information that you explicitly enter, including:

  • Profile details (name, age, gender, photo ID type and number)
  • General details (email address, city, state, country, pincode)
  • Custom field alias configurations

All of this information is stored exclusively in your browser's local storage using the Chrome storage.local API. It never leaves your device.

3. Data Transmission

Smart Form Filler does not transmit any data to any external server, third party, analytics service, or remote endpoint. There are no network requests made by this extension — not even for updates or telemetry.

4. Permissions Explained

  • activeTab — Used to interact with the current tab's form inputs when you click "Fill Page Now". The extension cannot access tabs you haven't opened or pages you haven't visited.
  • storage — Used to save your profiles, general details, and alias settings locally on your device using Chrome's built-in storage API.
  • host_permissions (<all_urls>) — Required so the extension's content script can detect and fill form inputs on any website you visit. This permission is used solely to read and write form field values on pages you navigate to. No page content is stored or transmitted.

5. Third-Party Services

This extension does not use any third-party services, SDKs, analytics libraries, or advertising networks.

6. Data Deletion

You can delete all stored data at any time by clicking the Clear All button in the extension popup, or by uninstalling the extension. Uninstalling removes all locally stored data permanently.

7. Children's Privacy

This extension is not directed at children under the age of 13. We do not knowingly collect information from children.

8. Changes to This Policy

If we update this privacy policy, the updated version will be published at this URL with a revised date. Continued use of the extension after any changes constitutes acceptance of the updated policy.
